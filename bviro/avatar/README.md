# bviro/avatar — شخصية «بدر الريسي» الرقمية

**اقرأ `CHARACTER.md` قبل أي عمل على الشخصية.** هو المرجع الوحيد ودليل الاستخدام: الشكل المقفل، المراجع،
الوضعيات، الصوت، حركة الشفاه، الأدوات المسموحة والممنوعة، فحوص ما قبل التسليم، وسجل قرارات بدر.

- `reference/` النسخة الرئيسية والزوايا العشر.
- `poses/` الوضعيات المعتمدة (`poses_sheet.jpg` يعرضها).
- `mouth/` أشكال الفم والرمشة.
- `tools/` سكربتات المونتاج.

الشخصية مقفلة: لا يتغير الشكل ولا الجسم ولا الابتسامة. أي تغيير يحتاج موافقة بدر الصريحة ويُسجَّل في `CHARACTER.md`.
