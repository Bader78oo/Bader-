# Bviro hook library (first 3 seconds)

Use with `scripts/hook_lab.py` (render 3–4 openings, score them, pick the best) and
`scripts/hook_score.py` (0–100 score + fixes). Write hooks in Bader's Omani/Gulf register, ≤ 7 words on
screen (extra words go in `sub`). Never invent statistics — a number hook needs a real number from Bader.

## The 3-second checklist (what `hook_score.py` measures)
1. **Frame 1 already moves** — start the clip mid-action (`in` later), punch-in or whip; never a still.
2. **Promise on screen by 0.3–0.5 s** — `hook.s` ≤ 0.3, big, high-contrast, not over a face.
3. **Sound hits at 0.0 s** — `sfx` impact/whoosh at t=0; voice starts ≤ 0.3 s.
4. **A face or one clear subject** — eyes to camera stop the scroll; a VR headset hides the eyes, so pair it
   with a face shot inside the first 3 s.
5. **One change before 3 s** — a cut, zoom punch or flash (`open_shots` with two shots).
6. **Payoff promised, not given** — the hook opens a loop the body closes (Vida Media structure).

## Opening shot recipes (visual hook)
- **Transformation** (strongest): wireframe → real (villa `v72`, hologram tower `v71`).
- **Face + wonder**: person lifting a headset with a smile / family reacting (`v73`) — adds the face.
- **Impossible view**: POV drone over Muttrah / canyon edge (`w102`, `w103`).
- **Hand interaction**: hand drawing a hologram (`w101`) — pair with a face cut before 3 s.
- Always: impact at t=0, zoom/flash at the first cut, text ≤ 7 words by 0.3 s.

## Loop back (rewatch)
End on a frame that echoes the first (same place / same person, now finished) so the reel loops cleanly —
e.g. the developer and the finished tower (`realestate-vr.json`).
